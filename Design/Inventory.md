Third-party managed libraries also in `Managed\`, used by the presentation layer: NGUI (UI),
Fabric (audio), CinemaDirector and Cinemachine (cutscenes and cameras), LeanTween, PlayMaker,
uScript runtime, Ionic.Zip, LZ4, BugSplat (crash reports).

**The split that makes the rebuild tractable:** the simulation (`BBI.Game`, `BBI.Core`,
`BBI.Game.Data`, about 117k lines) does not touch Unity at all. It runs at
`SimController.kSimTicksPerSecond = 8`, computes in `Fixed64`, and every state object has a
`GetChecksum()` combined through `Checksum` (with an export to JSON), which is what the original
uses to detect desyncs and what the rebuild uses to prove itself.

### Floats in the simulation

The simulation's arithmetic is integer: `Fixed64` is a `long` with 32 fractional bits; its
trigonometry and exponentials use lookup tables (`kTrigLookupSize = 16`, `kExpLookupSize = 56`).
The few `float`s in `BBI.Game` are not simulation state (camera and marker save data, music
events, frame-time statistics), with two exceptions the port must copy exactly:
- Authored data enters through `Fixed64.UnsafeFromFloat`/`UnsafeFromDouble`:
  `(long)(value * 4294967296.0)` with saturation, truncating. Done once, at load.
- `EconomyManager` (AI) rounds `float` resource ratios with `Math.Round`, which rounds halves to
  even: `std::nearbyint` in the default rounding mode, never `std::round`, and no fast-math.

## 3. Content

81 scenes in the build, 165 serialized files, 446,610 objects. A campaign mission is several scenes
loaded together (`M04-WorldArt` + `M04-Audio` + `M04-Design-NIS`); multiplayer maps have a
WorldArt scene and one or more design scenes. 36 groups in all (`manifest.json` → `groups`).
