Suppression keys on the combat flag that already replicates — PvpFlags.engagedUntilTick (02 §8.2), the same 60-second flag that blocks docking and safe log-off. That matters for the 07 §5 test: "in combat" is not a UI heuristic to be tuned, it is a replicated field, so the suppression rule is a pure function of state and can be asserted rather than eyeballed. Suppressed toasts are queued, not dropped, and drain when the flag clears.

Two zones, and the split is deliberate. Critical takes centre-top because it is the one class that may interrupt — it is near the eye's resting point during a fight and carries a single action. Everything else stacks bottom-right, inside thumb reach on a landscape tablet (U5) and clear of both the roster drawer and the order puck's working area. No toast ever overlaps the context bar: the bar is where orders are issued, and a toast that covers `ATTACK` mid-fight is a lost engagement.

The bounce state is not a new component — it is 03 §9.5's authority bounce, and every rejected order already owes one. §4 THE PUSH NOTIFICATION PATH — F8
THE CONTRADICTION
03 §9.6 asserts the feature outright: "wall-time jobs surface as push notifications." Industry queues and skill training both run on wall-clock time, so a player who is not in the client needs telling.
But 00 §2.3's allow-list has no row for the Windows notification platform, and the policy is that nothing enters without one. The feature is asserted by one document and denied by another.
This design cannot resolve that — it is an owner's call about scope and the allow-list, not a UX question.
WHAT THE DESIGN DOES ABOUT IT
▸ Wall-time completion is a priority level in §1 regardless of transport. In-client it is a toast; out-of-client it is whatever F8 decides, or nothing.
▸ The taxonomy is transport-agnostic, so accepting or rejecting F8 changes one delivery adapter and no part of this design.
▸ If F8 is rejected, the fallback is a job-completion digest on next login — which the Industry and Character screens need anyway, so it is not wasted work.
Recommendation: defer F8 past Slice A′. It is an OS integration with a security and privacy surface, and A′ ships the tactical HUD alone (F9).
