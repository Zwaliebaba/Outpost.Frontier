Four independent channels, never collapsed into one: silhouette carries hull class, size carries tonnage, colour carries relationship, and a ring decoration carries PVP flag. Colour is never the only carrier of a state — every flag is also a distinct ring geometry, which is what makes the three colour-vision palettes (03 §9.7) a swap rather than a redesign.

Flags are drawn as rings around the glyph rather than as a hue change, because a hostile Criminal and a neutral Criminal must both read as attackable while still reading as different parties. Ring geometry alone separates the four flag states with colour removed entirely — swap the palette above to check it.

Drawn on the selection and on locked targets only (decided). Flags are Public, so every ring in view could legally be drawn — but a lawless region at the 1,024-entity cap would then be a screen of rings, and the states that matter are attached to something you are about to shoot or be shot by. The information is not withheld: it is one tap away on any entity, and the de-clutter merge never folds a flagged entity into a chip — a flagged hull always survives as its own glyph.

§5 LEGIBILITY PLATE the R3 F13 test — each glyph drawn to its stated longest axis, tonnage scaling suspended
{{ row.label }}
{{ row.note }}

The floor is 20 px, not U2's 48 px. U2 governs what a finger must be able to hit, which the press-hold magnifier already solves for dense clusters; this is what an eye must be able to tell apart, and it is the tighter constraint in a 1,024-entity view. Tonnage scaling is suspended on this plate on purpose: the size channel would flatter the result by separating glyphs that their shapes alone do not.

Two collisions survive to 20 px and both sit inside a role family. Cruiser and Structure — hexagon against octagon — are the worse pair, separable here only because Structure never moves and never carries a heading; if that ever stops being true the taxonomy needs a different glyph, not a bigger one. Frigate and Battleship are the second, resolved by giving the Battleship a twin-pronged stern rather than by making it larger, since size is already carrying tonnage. Interceptor survives even the failing 14 px row — a thin spike is the most robust silhouette in the set, which is worth remembering when a twelfth class is proposed.

A glyph never shrinks below its legible floor; it is replaced. That keeps 04 §6.3 satisfiable — a merged chip states an extent and a count and claims nothing about position — and it makes the de-clutter step a pure function of replicated fields, which is what F10's determinism requirement demands.

§7 ATLAS, DPI, AND WHAT WAS DECIDED
ATLAS STRATEGY — RECOMMENDED
▸ Dedicated icon atlas, not the R8 text pages (03 §9.7). Glyphs are multi-channel and permanently resident; text pages are R8 and LRU-evicted.
▸ Authored as SDF, one channel, so a single source resolves 12 px to 96 px and every UI scale from 0.8× to 1.6× without a mip set or a second authoring pass.
▸ Residency class Critical (03 §5.3) — an evicted icon page is an unreadable battle, not a soft degrade.
▸ iconAtlasSlot already exists in HullVisualRow (08 hull-table proposal §5), so the binding needs no new field — but it is a per-type value while this taxonomy is per-class. Someone must say which wins.
DECIDED — 2026-08-08
✅ Glyphs are per-class — 11 slots, closed. iconAtlasSlot is therefore a per-type field pointing at a per-class glyph, and the bake should validate that every type in a class resolves to the same slot rather than leaving it free.
✅ Own takes a fourth hue. All three palettes above carry four; knowing which ships are yours outranks the headroom.
✅ Allied stays, on the assumption D7's alliance entity lands. If D7 is rejected the Allied row collapses into Neutral and no other part of this system changes.
✅ Cruiser/Structure collision accepted, conditional on Structure remaining static and heading-less. A mobile structure re-opens this and should be treated as a taxonomy change, not an art request.
⬜ R3 F13 stays open — if the 20 px floor cannot hold on an Adreno-class panel, the fix is fewer hull classes, which is a design change and not an art one.
